# Claire & Grace's Lab

克莱尔和格蕾丝的科学实验室 —— 一个苹果风格的初高中理化生虚拟实验室（参考 NoBook 式虚拟实验课程）。

单文件应用：直接用浏览器打开 `index.html` 即可，无需构建、无外部依赖（仅可选加载 Google Fonts 的 Noto Sans SC 作为非苹果设备的中文字体回退）。

## 三种模式

1. **跟课本做** —— 按教材步骤完成实验，每步实时判定，完成后总结知识点。
2. **自由探索** —— 无步骤沙盒（化学混合台 / 电学工作台 / 显微镜台），现象自动写入观察记录并附「为什么」。
3. **还原挑战** —— 读题目，用器材还原实验场景，提交后判定并给出解析。

## 内置实验引擎

- **化学混合台**：试剂规则引擎（石蕊/酚酞变色、中和、制取 O₂/CO₂/H₂、金属活动性、蓝色沉淀），气体检验（石灰水、带火星木条）与 pH 试纸。
- **电学工作台**：插槽式电路（串联 / 并联两种拓扑），闭合回路判定、灯泡发光、导体绝缘体探究、并联支路互不影响。
- **光学工作台**：光具座 + 凸透镜成像（1/f = 1/u + 1/v 实时计算），移蜡烛、找清晰像、观察虚像。
- **显微镜台**：制片流程（滴水→取样→盖片→染色）+ 调焦滑杆，洋葱表皮 / 口腔上皮两种标本。
