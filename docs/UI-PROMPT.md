# 给设计工具的提示词：netX 界面原型

把这一整份贴给设计 AI（Figma Make / v0 / Claude / GPT 等）。它是自足的，不需要
再补充上下文。做完把产物放回 `design/` 目录，我这边直接照着实现。

---

## 一、你要做什么

为 **netX** —— 一个 Windows 桌面下载器 —— 做完整的界面原型。

这不是"给个风格参考"。我需要的是**每一屏的最终值**：尺寸、间距、颜色、字号、
字重、行高、圆角、每个状态、动效时长与缓动曲线。落地的人不应该需要猜任何一个数。

## 二、必须遵守的硬约束

这些不是偏好，是目标平台的物理限制。违反其中任何一条，产物就没法落地。

1. **技术栈是 WinUI 3（Windows App SDK 2.2）+ XAML**，不是网页。
   凡是只有浏览器才有的能力都不能作为设计的基础：
   - `backdrop-filter` 毛玻璃 → WinUI 只有 `AcrylicBrush`，效果不同。要用请明确
     标注"此处期望亚克力"，并给一个不支持时的纯色兜底值。
   - CSS 会把过大的圆角夹到边长一半，**WinUI 不会夹**，会画成透镜形。所以圆角
     请直接给最终值，不要写 `999` / `50%`。
   - `letter-spacing`、`line-height` 请给具体像素值，不要给 `normal`。
2. **字体只能用 Windows 自带的**：`Segoe UI Variable`（西文）+ `微软雅黑`（中文）。
   **不要基于 SF Pro / Inter / 思源黑体设计**——那些字体目标机器上没有，字宽和
   行高会全部变形。这是上一版差异最大的来源之一。
3. **不要用位图**。所有图标必须是**单色描边路径**，画在 **24×24 的 viewBox** 里，
   只给 `d` 属性（`M … L … a …`），线宽单独给（我们会转成 XAML 的 PathGeometry）。
   彩色插画、渐变图标、阴影图标都无法转换。
4. **界面语言是简体中文**，请直接用中文写文案，不要写英文再让我翻译。
   中文字符宽度和西文差别很大，用占位英文设计出来的排版会崩。
5. **必须给浅色和深色两套色值**。Windows 用户会跟随系统主题。

## 三、你要交付什么（按优先级）

**首选：WinUI 3 XAML。** 我能直接读、直接用。一屏一个 `UserControl`，另加一个
`ResourceDictionary` 放色值和样式。哪怕结构不完美也没关系，值对就行。

**次选：HTML + CSS 静态原型**，一屏一个文件，外加一份规格表（下面第五节的格式）。
如果走这条，CSS 里请只用 WinUI 能对应的属性，并遵守第二节的约束。

**最低要求：标注齐全的图 + 规格表。** 图上必须能读出所有数值。

无论哪种，都请附一份 `TOKENS`（颜色 / 圆角 / 字号 / 间距的命名表），这样我改一个
值就能全局生效。

## 四、屏幕清单（一共 23 屏，全部都要）

### 窗口外壳
应用是**两个独立的桌面小窗**，等宽等高，可以磁吸贴在一起（贴合侧的圆角归零）。
窗口上方还有一个悬浮的"灵动岛"速度指示器。

| # | 屏 | 说明 |
|---|---|---|
| 1 | 主窗 · 有任务 | 任务列表，5 条 + "展开更多 N 项" |
| 2 | 主窗 · 第一次打开 | **一个任务都没有**。这是所有人看到的第一眼，必须专门设计，不能是空白 |
| 3 | 主窗 · 筛选无结果 | 有任务但搜索/筛选没命中 |
| 4 | 主窗 · 列表展开 | 展开后全部任务 |
| 5 | 主窗 · 小图模式 | 紧凑行高，隐藏副行 |
| 6 | 主窗 · 已完成分段 | 分段控件切到"已完成" |
| 7 | 任务行 · 悬停操作 | 从右侧滑入的 暂停/继续 与 删除 |
| 8 | 新建菜单 | 标题栏 + 号弹出的菜单 |
| 9 | 显示与排序菜单 | 排序方式、主题、分类筛选 |
| 10 | 任务右键菜单 | 打开文件、在文件夹中显示、暂停、重下、复制链接、删除… |

## 七、几件容易踩的事

- **空状态不是"没内容"**，是一屏正经设计。第 2 屏（第一次打开）请当成主屏来做。
- **中文文案会换行**，副行、按钮、表单标签都请按最长的中文情况排版。
- **数字要等宽**（速度、进度、大小在不停跳动），请标注使用等宽数字。
- **别只画"一切正常"的状态**：出错、暂停、排队、校验失败都要有明确样式。
- 目标窗口只有 536 宽，**不要设计需要横向滚动的表格**。

## 八、交回来之后

把产物放进仓库的 `design/` 目录（XAML 放 `design/xaml/`，HTML 放 `design/html/`，
规格表放 `design/spec/`）。

我这边有一条流水线：程序会自己走一遍全部 23 屏、逐屏渲染成 PNG，再和你给的原型
逐项比对尺寸。所以你给的数越具体，对齐得越快。
